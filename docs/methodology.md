
# Methodology

## 1. Study Area
Voi Town, Taita Taveta County, Kenya.

## 2. Data Sources
- Landsat 8 Collection 2 Level-2
- Landsat 9 Collection 2 Level-2
- Google Earth Engine

## 3. Study Period
June–September seasonal composites,
2016–2026.

## 4. Data Preprocessing
- Cloud and shadow masking
- Surface reflectance scaling
- Land Surface Temperature retrieval
- NDVI calculation
- NDBI calculation

## 5. Indicator Analysis
- Land Surface Temperature (LST)
- Normalized Difference Vegetation Index (NDVI)
- Normalized Difference Built-up Index (NDBI)

## 6. Temporal Trend Analysis
Annual statistics and linear regression.

## 7. Heat Hotspot Classification
LST classified into four relative
temperature classes using quartiles.

## 8. Mapping and Visualisation
Google Earth Engine, Python and QGIS.

## 9. Limitations
Satellite-derived LST represents land
surface temperature, not air temperature.
